# Detonado Counting Sort & Radix Sort LSD

Material de apoio sobre **Counting Sort** e **Radix Sort LSD**, com teoria,
questões comentadas e uma demonstração visual interativa.

## Demonstração interativa

💃 **[Acesse o Detonado Radix Sort](https://guiv3n.github.io/Detonado-couting-sort-radix-LSD/)**

A página mostra o Counting Sort passo a passo e explica como ele é usado como
subrotina estável pelo Radix Sort LSD. Também é possível informar outros
números e acompanhar a ordenação visualmente.
