Parte 1 · A subrotina

Primeiro,
Counting Sort.

Antes de ordenar dígito por dígito, precisamos de uma forma estável de organizar valores inteiros. Counting Sort faz isso contando ocorrências — sem comparar pares.

IDEIA CENTRAL

Se sabemos quantas vezes cada valor aparece, sabemos quantos lugares reservar para ele na saída.

Como funciona

Três momentos,
uma saída ordenada.

Vamos usar A = [4, 2, 2, 8, 3, 3, 1]. O maior valor é 8, então C tem posições de 0 a 8.

  1. 01

    Conte as ocorrências

    Para cada valor x da entrada, faça C[x]++. Ao final, C informa quantas vezes cada número apareceu.

    C = [0, 1, 2, 2, 1, 0, 0, 0, 1]
  2. 02

    Some acumuladamente

    Faça C[i] += C[i−1]. Agora C[i] significa: “quantos elementos são menores ou iguais a i?”.

    C = [0, 1, 3, 5, 6, 6, 6, 6, 7]
  3. 03

    Preencha a saída de trás para frente

    Para cada x, use C[x]−1 como posição em B e depois diminua C[x]. Ler A ao contrário preserva a estabilidade.

    B = [1, 2, 2, 3, 3, 4, 8]

Uma imagem mental melhor

A acumulada reserva cadeiras.

Se C[3] vale 5, existem cinco elementos menores ou iguais a 3. Portanto, o último 3 ocupa a cadeira de índice 4. Depois usamos a cadeira anterior.

Implementação em C++

O algoritmo completo.

Esta versão ordena inteiros não negativos. As três regiões destacadas correspondem exatamente às três etapas da animação.

  • Tempo: O(n + k)
  • Memória: O(n + k)
  • Estável: sim, porque preenche B de trás para frente
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

void countingSort(vector<int>& A) {
    int maior = *max_element(A.begin(), A.end());
    vector<int> C(maior + 1, 0);
    vector<int> B(A.size());

    // 1. Conta quantas vezes cada valor aparece
    for (int x : A)
        C[x]++;

    // 2. Calcula as posições acumuladas
    for (int i = 1; i <= maior; i++)
        C[i] += C[i - 1];

    // 3. Monta a saída estável, da direita para a esquerda
    for (int i = (int)A.size() - 1; i >= 0; i--) {
        int x = A[i];
        B[C[x] - 1] = x;
        C[x]--;
    }

    A = B;
}

Parte 2 · A conexão

O Radix LSD não substitui o Counting Sort.

01

Só existem 10 chaves

Em cada passada, o dígito está entre 0 e 9. Portanto, C sempre tem tamanho 10.

02

É rápido por passada

Cada chamada custa O(n + 10), sem comparar um número com outro.

03

Precisa ser estável

A ordem obtida nas unidades deve sobreviver quando ordenamos pelas dezenas.

No Radix, muda apenas a chave: int digito = (A[i] / expoente) % 10;

Radix LSD em C++

A subrotina dentro do algoritmo.

radixSort percorre as casas decimais. Em cada volta, chama countingSortPorDigito, que usa somente o dígito indicado pelo expoente.

  • expoente = 1: unidades
  • expoente = 10: dezenas
  • expoente = 100: centenas
#include <algorithm>
#include <vector>
using namespace std;

// Counting Sort estável usando apenas um dígito
void countingSortPorDigito(vector<int>& A,
                           long long expoente) {
    int n = (int)A.size();
    vector<int> B(n);
    int C[10] = {0};

    // 1. Conta o dígito atual de cada número
    for (int x : A) {
        int digito = (x / expoente) % 10;
        C[digito]++;
    }

    // 2. Calcula as posições acumuladas
    for (int i = 1; i < 10; i++)
        C[i] += C[i - 1];

    // 3. Preenche B da direita para a esquerda
    for (int i = n - 1; i >= 0; i--) {
        int digito = (A[i] / expoente) % 10;
        B[C[digito] - 1] = A[i];
        C[digito]--;
    }

    A = B;
}

void radixSort(vector<int>& A) {
    if (A.empty()) return;

    int maior = *max_element(A.begin(), A.end());

    // Unidades, dezenas, centenas...
    for (long long expoente = 1;
         maior / expoente > 0;
         expoente *= 10) {
        countingSortPorDigito(A, expoente);
    }
}
